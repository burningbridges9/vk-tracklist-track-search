# VK Tracklist Search

Расширение для Chrome (Manifest V3), которое находит треклисты в постах **vk.ru** и добавляет в конце каждой строки кнопку поиска трека в аудио VK. Работают и нумерованные треклисты, и списки без номеров (например, с заголовком `Tracklist:`).

Подробное описание задачи, разметки VK и правил распознавания — в [`HANDOFF.md`](HANDOFF.md).

Было:

```text
04 Grum - Stay With Me
```

Стало (в конце строки появляется кнопка с лупой):

```text
04 Grum - Stay With Me  ⌕
```

Клик открывает новую вкладку с уже заполненным поиском:

```text
https://vk.ru/audios123456789?q=Grum%2520-%2520Stay%2520With%2520Me
```

## Установка

1. Возьмите архив `dist/vk-tracklist-search-1.1.0.zip` и распакуйте его (внутри папка `vk-tracklist-search`), либо используйте уже собранную папку `dist/vk-tracklist-search`.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json` (это `vk-tracklist-search` из архива; для разработки можно выбрать папку `extension/`).
5. Обновите открытую вкладку VK (`F5`) — расширение не внедряется в страницы, которые были открыты до установки.
6. Откройте пост с треклистом.

Клик по иконке расширения на панели Chrome открывает настройки.

## Как это работает

1. Content script на `vk.ru`/`vk.com` ищет тексты постов: `[data-testid="post_text"]`.
2. Текст разбирается на строки по `<br>` и служебным разделителям абзацев, которые VK рисует как `div` шириной 0.
3. Строка считается треком, если она начинается с номера (1–3 цифры) и содержит разделитель «исполнитель — название»:

   ```text
   04 Grum - Stay With Me
   1. Artist – Title
   [00:12] 03 Artist - Title (Remix)
   ```

   Строки-заголовки блоков (`Progressive Pick:`, `Tune Of The Week:`) под шаблон не подходят и пропускаются.

   Если нумерации нет, строка всё равно считается треком при одном из условий:

   - выше в тексте есть заголовок `Tracklist:`, `Треклист:`, `Playlist:` — тогда берутся все строки «исполнитель — название» после него;
   - иначе в посте есть непрерывный блок из 5 и более таких строк.

   Название выпуска до заголовка (например, `Elias Erium - The Outer Experience 063 (Live from Stereo, Part 2)`) треком не считается.
4. Если в посте набралось минимум `N` подходящих строк (по умолчанию 3; для блока без заголовка — 5) **и** в посте есть аудио- или видеовложение, в конце каждой строки вставляется ссылка-кнопка.
5. Кнопка не мешает выделять и копировать текст, поддерживает Ctrl+клик и средний клик. Обычный клик открывает поиск в новой вкладке (настраивается).

Расширение следит за лентой через `MutationObserver` и за SPA-переходами VK, поэтому кнопки появляются и в подгружаемых постах, и после переходов без перезагрузки. При повторной отрисовке поста кнопки добавляются снова, дубликаты не создаются.

### Обязательное условие: аудио или видео

По умолчанию кнопки появляются только в постах, где есть аудио- или видеовложение. Это отсекает случайные нумерованные списки. Признаки вложения:

- `audio` / `video`;
- `data-testid` с `music`, `audio`, `video` (например, `music-track-overlay-badge`, `musicattach-playbackcontrol`);
- старые классы `AudioAttachment` / `VideoAttachment`.

Пост только с фотографией (без музыки/видео) кнопок не получает. Если нужно работать и с чисто текстовыми треклистами, снимите галочку **«Только посты с аудио или видео»** в настройках.

## Адрес поиска и ID владельца аудио

Ссылка строится так:

```text
https://vk.ru/audios<ID>?q=<запрос>
```

- `<ID>` — число из адреса вашей музыки (`vk.ru/audios123456789`). Расширение определяет его автоматически, когда вы открываете свою страницу музыки: из адреса `/audios<ID>`. Найденный ID сохраняется в `chrome.storage.local` и используется на всех страницах. При необходимости ID можно вписать вручную в настройках.
- Пока ID не определён, используется `https://vk.ru/audios?q=...`; при открытии своей страницы музыки расширение запоминает ID и дальше подставляет его.
- Параметр `q` кодируется дважды (`Grum - Stay With Me` → `Grum%2520-%2520Stay%2520With%2520Me`), потому что VK сам кодирует его ещё раз — именно такие адреса генерирует сайт. Если у вас поиск открывается, но в строке поиска видно `%20`, переключите **Кодирование запроса** на «Обычное».

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Расширение включено | вкл. | Полностью выключает кнопки и обработку страниц. |
| Только посты с аудио или видео | вкл. | Главное условие появления кнопок. |
| Минимум строк в треклисте | 3 | Для нумерованных строк и треклистов с заголовком `Tracklist:`; для блока без заголовка нужно минимум 5 строк. |
| Открывать поиск в новой вкладке | вкл. | Иначе поиск откроется в текущей вкладке. |
| Кодирование запроса | двойное (`%2520`) | Как в адресах VK; переключите, если поиск не подхватывает запрос. |
| ID владельца аудио | пусто | Ручной ID, если автоопределение не сработало. |

Настройки хранятся в `chrome.storage.sync` и применяются сразу, без перезагрузки страницы.

## Если кнопки не появились

1. **Обновите вкладку VK** — content script не попадает в уже открытые страницы.
2. Проверьте, что расширение включено (иконка → настройки).
3. В посте должно быть аудио или видео. Пост только с фото или только с текстом кнопок не получит.
4. В тексте должно быть минимум 3 строки вида `01 Исполнитель - Название` (число и дефис с пробелами), либо треклист без номеров с заголовком `Tracklist:` / `Треклист:`, либо блок из 5+ строк «Исполнитель - Название» подряд.
5. VK мог изменить разметку — расширение завязано на `data-testid="post_text"` и `<br>`. Если разметка поменялась, кнопки перестанут появляться; напишите, и я обновлю селекторы.
6. Комментарии не обрабатываются — расширение работает только с текстами постов.

Если кнопка есть, но VK открывает музыку без запроса — задайте ID владельца аудио в настройках (его видно в адресе `vk.ru/audios<ID>`).

## Приватность

Расширение не отправляет данные в сеть: оно только читает DOM страницы VK и открывает ссылку по клику. Настройки и определённый ID лежат в локальном хранилище браузера.

## Структура проекта

```text
extension/            исходники расширения (можно грузить как unpacked)
  manifest.json
  common.js           настройки по умолчанию
  content.js          разбор постов и кнопки
  content.css         стиль кнопки
  background.js       открытие настроек по клику на иконку
  options.html/css/js страница настроек
  icons/              иконки 16/32/48/128
test/
  fixture.html        макет постов VK для тестов
  run-tests.mjs       тесты на jsdom (47 проверок)
  .deps/              jsdom (ставится отдельно)

  make_icons.py       генерация иконок (Pillow)

```

## Разработка

### Тесты

```bash
node test/run-tests.mjs
```

Нужен Node.js 20+. jsdom уже установлен в `test/.deps`; если папки нет:

```bash
pnpm add jsdom --dir test/.deps
# или
npm install --prefix test/.deps jsdom
```

Тесты проверяют: 37 кнопок в нумерованном треклисте с музыкой, треклист без номеров с заголовком `Tracklist:` (25 кнопок), блок без заголовка (6 кнопок) и отсутствие кнопки у названия выпуска, ссылки с двойным кодированием, позицию кнопки в конце строки, неразобранные строки, выключенное расширение, манифест и страницу настроек.

### Сборка

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

Скрипт пересобирает `dist/vk-tracklist-search` и `dist/vk-tracklist-search-1.1.0.zip`.

### Иконки

```bash
python tools/make_icons.py
```

Нужен Pillow.

## Ограничения

- Работает на десктопных `vk.ru` и `vk.com`; мобильная версия не поддерживается.
- Разметка VK — внутренняя и может меняться; селекторы собраны по актуальному интерфейсу (`vkit`-классы, `data-testid`).
- Треклист должен быть нумерованным и содержать разделитель «исполнитель — название».
- Кнопка добавляется в конец строки, а не делает кликабельным весь текст: так она не мешает выделению и копированию.
